# Write Mathematics

An agent skill for drafting, editing, explaining, and reviewing mathematical exposition with attention to correctness, rigor, structure, notation, proofs, and typesetting.

## Install

Install for Codex across projects with the [Vercel Skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add myousefi/write-mathematics
```

The repository contains one skill, defined in `SKILL.md`, with supporting material in `references/`.

## Sources

This skill compiles and adapts guidance from several useful sources on mathematical writing:

- Paul Halmos, [“How to Write Mathematics”](https://sites.math.rutgers.edu/~ceu11/Courses/halmos.pdf), a gem of an essay.
- Donald Knuth, Tracy Larrabee, and Paul Roberts, [*Mathematical Writing*](https://cs.stanford.edu/~knuth/klr.html), a thorough treatment. The 27 rules in the first six pages are especially useful for readers in a hurry.
- Steven G. Kleiman, [“Writing a Math Phase Two Paper”](https://web.mit.edu/mathp2/www/piil.html), with plenty of practical guidance.
- Dimitri P. Bertsekas, [“Ten Simple Rules for Mathematical Writing”](https://faculty.engineering.asu.edu/bertsekas/ten-simple-rules-for-mathematical-writing/), which offers a structured approach.
